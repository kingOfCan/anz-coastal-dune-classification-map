# anz-coastal-dune-classification-map

A 10 m coastal dune classification map for Australia and New Zealand.

---

# Dataset Description

The mapped dune classes include:

* Active dunes
* Foredunes
* Semi-stabilized dunes
* Stabilized dunes
* Sandy beaches
* Water
* Wetlands

---

# Spatial Reference Information

| Property                    | Value                    |
| --------------------------- | ------------------------ |
| Coordinate Reference System | EPSG:3857                |
| Spatial Resolution          | 10 m                     |
| Raster Format               | GeoTIFF                  |
| Data Type                   | 8-bit RGB                |
